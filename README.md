# Nsociety

Welcome to **NSociety**, a project created by the **C.T.A (Cyber Threat Alliance)** team.

Thank you for checking out our work. We truly appreciate your support, feedback, and interest in what we’re building. NSociety is a cybersecurity-focused project made for learning, experimentation, and educational exploration in a controlled environment.

Our goal is to keep improving and expanding this project as we grow as developers and security enthusiasts.

---

## Installation (Kali Linux)

Run the following commands in your terminal:

```bash
git clone https://github.com/Cyberthreatalliance-cta/Nsociety.git
cd NSociety
sudo bash NSociety.sh
```
